FAQ

Preguntas frecuentes

¿Qué es el prompt injection?

Es una técnica donde un atacante manipula los prompts para hacer que tu LLM haga cosas que no debería — como revelar información confidencial, ignorar reglas de seguridad o ejecutar acciones no autorizadas.

¿Cuánto tiempo toma implementarlo?

La integración básica toma menos de 5 minutos. Instalas el SDK, añades una línea de código y tu AI está protegido. Para configuraciones avanzadas, nuestro equipo te ayuda en menos de 24 horas.

¿Afecta la velocidad de mi AI?

No. Nuestro firewall agrega menos de 2ms de latencia. Los usuarios nunca notan la diferencia. Procesamos millones de requests diarios con tiempos de respuesta imperceptibles.

¿Funciona con cualquier LLM?

Sí. Funciona con OpenAI (GPT-4, GPT-4o), Anthropic (Claude), Cohere, Llama, Mistral, y cualquier modelo self-hosted. Es compatible con cualquier API que acepte texto como input.

¿Puedo probarlo gratis?

Sí. Ofrecemos una demo interactiva en esta página y un plan gratuito con 1,000 requests/mes para que pruebes antes de comprometerte.
